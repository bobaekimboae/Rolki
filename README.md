# Rolki · 매물 숏폼

Rolki의 새 영상 작성 흐름을 참고해 한국어로 만든 중고차 매물 숏폼 제작기입니다. 차량 사진과 매물 정보를 브라우저에서 편집하고, 선택한 형식으로 WebM 영상을 만들어 미리 보고 내려받을 수 있습니다.

## 사용 방법

1. [Rolki 웹 앱](https://bobaekimboae.github.io/Rolki/)을 엽니다.
2. 차량 사진을 한 장 이상 올립니다. JPG, PNG, WebP를 지원하며 파일당 최대 20MB, 최대 40장입니다.
3. 제조사, 모델·세부 트림, 연식, 주행거리, 가격 등 필요한 정보를 입력합니다.
4. 매거진, 카드, 벤토, 차량 정보 등 영상 형식을 선택하고 글꼴·색상·음악을 고릅니다.
5. **주문 내용 확인 → 영상 제작하기**를 누릅니다. 제작된 영상마다 미리보기와 다운로드 버튼이 표시됩니다.

## 실제 동작 범위

- 영상은 브라우저의 Canvas와 MediaRecorder로 제작합니다. 기본 출력은 9:16이며, 선택한 게시물 형식은 3:4, 1:1, 16:9로 렌더링합니다.
- 선택한 음악은 로컬 Web Audio로 합성해 영상에 포함하거나, 음악 없음으로 제작할 수 있습니다.
- 사진은 서버로 전송되지 않습니다. 선택한 사진을 정렬하고 삭제할 수 있습니다.
- 화면에서 `예시 사진 3장 불러오기`를 눌러 샘플 사진으로 미리 제작해 볼 수 있습니다.
- 매물 링크는 주소 형식만 확인합니다. 외부 매물의 사진·정보를 자동으로 읽는 기능은 아직 연결되지 않았으며, 이는 사이트별 CORS와 접근 정책을 해결할 별도 서버가 필요합니다. 링크를 붙여넣어도 매물 내용이 자동 입력되지는 않습니다.
- 생성 파일은 WebM입니다. 기기와 브라우저에 따라 재생 호환성이 다를 수 있습니다. MP4 변환과 AI 내레이션은 포함하지 않았습니다.

## 로컬 개발

```bash
pnpm install
pnpm run dev -- --host 0.0.0.0
pnpm run build
pnpm run test:sites
```

이 프로젝트는 GitHub Pages의 `/Rolki/` 경로로 배포하도록 설정되어 있습니다. `main` 브랜치에 푸시하면 GitHub Actions가 정적 파일을 빌드하고 Pages에 배포합니다.
